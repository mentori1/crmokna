# CRM «Овсянников» — рабочая документация

CRM для бизнеса по продаже окон, стройматериалов и товаров для ремонта.
Заменяет ведение в Google Таблице: централизует заказы, клиентов, оплаты,
доставку и финансы. Данные берутся напрямую из рабочей Google Таблицы.

---

## 1. Как открыть (одна кнопка)

Дважды кликните по файлу **`Открыть CRM.command`** в папке проекта.

Что произойдёт автоматически:
1. Свежие данные подтянутся из Google Таблицы;
2. Запустится локальный сервер;
3. CRM откроется в браузере (`http://localhost:3457`).

Откроется чёрное окно терминала — **его нужно оставить открытым** (в нём
работает сервер). Свернуть можно, закрыть — нельзя. Чтобы выключить CRM —
закройте это окно.

> Первый запуск может попросить разрешение macOS: ПКМ по файлу → «Открыть».

С телефона: CRM открывается в браузере телефона по адресу компьютера в
локальной сети (`http://<IP-компьютера>:3457`) — при условии, что телефон и
компьютер в одной Wi-Fi сети. Интерфейс полностью адаптирован под телефон.

## 2. Откуда берутся данные (синхронизация)

```

        │   (Google Sheets API, service-account)
        ▼

        │
        ▼
data/orders.json, clients.json, suppliers.json, transactions.json
        │   (fetch при загрузке страницы)
        ▼
        CRM в браузере
```

- **Ключ доступа:** `sanya-498120-cee43b3a5917.json` (service-account
  `mentori@sanya-498120.iam.gserviceaccount.com`). Таблица расшарена на этот
  email. **Ключ нельзя выкладывать в открытый доступ** — он в `.gitignore`.
- **Ручная синхронизация:** `python3 import/sync_sheets.py`
  (или просто перезапустить через `Открыть CRM.command`).
- `data/meta.json` хранит время последней синхронизации.

### Важно про распознавание заказов
У старых заказов есть номер в столбце «№», а у новых (с 2023 г.) — нет.
Поэтому строка считается заказом **по наличию даты**, а не номера.
Если у заказа нет своего номера — присваивается технический `ЗК-NNNNN`.

## 3. Разделы CRM

| Раздел | Что показывает | Действия |
|---|---|---|
| **Дашборд** | Заказы, выручка, прибыль за период; долги; последние заказы; графики | Кнопки периода: 30 дней / Квартал / Полгода / Год / Всё время |
| **Заказы** | Все заказы (пагинация по 50), фильтр по статусу и датам | Открыть карточку, создать, редактировать |
| **Доставка** | Только открытые заказы и статусы их доставки | Сменить статус доставки в строке |
| **Клиенты** | Список с суммой покупок и задолженностью | Открыть карточку с историей заказов |
| **Поставщики** | Список с суммой закупок и долгом перед ними | Открыть карточку |
| **Финансы** | Выручка, прибыль, дебиторка, кредиторка; движение денег | Фильтр по типу и датам |
| **Склад** | Карточки товаров, остатки (задел на будущее) | — |

### Метрики дашборда за период
Кнопки **30 дней / Квартал / Полгода / Год / Всё время** пересчитывают
*заказы, выручку и прибыль* за выбранное окно (от сегодня назад).
Долги клиентов и поставщиков всегда показывают **текущий остаток**.

### Статусы заказа
Новый → В работе → Заказан у поставщика → Получен на склад → Доставляется →
Доставлен → Закрыт. Меняются в карточке заказа.

### Статусы доставки (раздел «Доставка»)
Не назначен → Машина едет за грузом → Груз отгружен → Груз на складе →
Отправлен клиенту → Получен клиентом. Меняются прямо в строке таблицы.
*(В планах: автозаполнение из почты.)*

## 4. Ввод данных вручную

**Новый заказ** (кнопка «+ Новый заказ» вверху или в разделе «Заказы»):
- ФИО клиента — поле с подсказками; можно вписать **нового** клиента;
- Телефон, даты, адрес;
- Продукция — **свободный ввод** названия + кол-во + закупка + продажа
  (можно добавлять несколько позиций кнопкой «+ Добавить позицию»);
- Поставщик — с подсказками, можно вписать нового.

Новые клиенты и поставщики создаются автоматически при сохранении.

**Редактирование заказа:** открыть заказ → кнопка «✏ Редактировать» —
те же поля, можно поменять ФИО, продукцию, цены, даты, поставщика.

> Важно: ручные правки в CRM живут только в браузере и **перезаписываются
> при следующей синхронизации** из Google Таблицы. Источник истины — таблица.
> (Двусторонняя запись CRM → Таблица — следующий этап разработки.)

## 7. Связи данных

```
clients ──1:N── orders ──1:N── order_items ──N:1── suppliers
                  │
                  └── transactions (приход от клиента / расход поставщику)
```
- У заказа есть позиции (продукция) с ценами закупки и продажи;
- Маржа = продажа − закупка;
- Долг клиента = сумма продажи − полученные оплаты;
- Долг поставщику = сумма закупки − оплаченное поставщику.

## 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| CRM не открылась | Закройте окно терминала и снова запустите `Открыть CRM.command` |
| Данные устарели | Перезапустите через `Открыть CRM.command` (синхронизация при старте) |
| «нет сети» при синхронизации | Откроются последние сохранённые данные; повторите при интернете |
| Порт занят | Скрипт сам перезапускает сервер на порту 3457 |
| Ошибка доступа к таблице | Проверьте, что таблица расшарена на `mentori@sanya-498120.iam.gserviceaccount.com` |
