## v15 — 2026-06-16
**Fix: глобальный поиск выдавал мусор.** При поиске по тексту без цифр
(название товара, имя клиента) условие `phone.includes(q.replace(/\D/g,''))`
давало `includes('')` → `true` для всех заказов → в выдачу попадали случайные
первые заказы. Выглядело как «поиск не работает».
- Телефонный матч только при наличии цифр в запросе (`qDigits && …`);
- Поиск по заказам расширен: + CRM-ID, + продукция внутри заказа
  (`items[].product_name`), + номер производства;
- В результатах показывается продукция заказа.

## Более ранние вехи (до GitHub, локальная разработка)

- **Синхронизация через Google Sheets API** (`import/sync_sheets.py`) —
  исправлена потеря ~3127 заказов (фильтр по дате вместо номера). Итог:
  **4941 заказ, 2021–2026, выручка ~151 млн ₽, прибыль ~34 млн ₽**.
- **Поле «Размеры»** в позициях заказа — авто-появление для окон/дверей и т.п.
- **Добавление платежей** в карточке заказа (клиент платит частями) +
  кнопки «+ Операция» (Финансы), «+ Товар» / «Приход» (Склад).
- **Раздел «Доставка»** со статусами доставки открытых заказов.
- **Ручной ввод** клиентов/поставщиков/продукции (свободный ввод + автосоздание).
- **Период на дашборде** (30 дней / Квартал / Полгода / Год / Всё время).
- Первичный импорт из CSV → переход на XLSX (реальные даты) → на API.
