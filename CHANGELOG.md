## v42 — 2026-07-01 — Подсказки адреса через Яндекс SuggestView
- Подсказки адреса переведены с HTTP-эндпоинта (резался CORS из браузера) на
  официальный браузерный `ymaps.SuggestView` — подгружается JS-API Яндекса и

- ⚠️ Нужен ключ типа **«JavaScript API и Геокодер»** (текущий ключ JS-API
  отклоняет: «Invalid API key»). Ключ — в `supabase-config.js`. Без валидного
  ключа поле адреса — обычный текст (ничего не ломается).

## v50 — 2026-07-01 — Подсказки адреса переведены на DaData
- Убран Яндекс.SuggestView (упёрлись в активацию ключа/домен). Подключён
  **DaData Suggestions API** — работает из браузера (CORS, без привязки к домену).
- При вводе ≥3 символов — выпадающий список (debounce 300мс); по клику
  подставляется полный адрес, а структура (регион/город/улица/дом/индекс/
  координаты/fias) сохраняется в новую колонку `clients.address_data` (JSONB)
  при создании заказа и в формах клиента.
- Токен — `window.DADATA_TOKEN` в `supabase-config.js` (бесплатный API-ключ из
  кабинета dadata.ru). Без токена поле — обычный текст, ничего не ломается.

  **4941 заказ, 2021–2026, выручка ~151 млн ₽, прибыль ~34 млн ₽**.

  кнопки «+ Операция» (Финансы), «+ Товар» / «Приход» (Склад).

- **Ручной ввод** клиентов/поставщиков/продукции (свободный ввод + автосоздание).
