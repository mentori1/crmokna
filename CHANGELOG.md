# История изменений — CRM «Овсянников»

Формат: версия кэша (`?v=N` в `index.html`) → что сделано.
Новые записи — сверху.

---

## v13 — 2026-06-04
**Fix (iOS):** поля дат в форме создания/редактирования заказа выезжали за
рамки, модалку можно было листать вбок на iPhone.
- `input[type=date]` → `-webkit-appearance: none` (на iOS была жёсткая min-width);
- `.modal-body { overflow-x: hidden }` — страховка от горизонтального скролла.

## v12 — 2026-06-04
**Таблицы → карточки на телефоне.** Вместо горизонтального скролла каждая строка
таблицы (заказы, доставка, клиенты, поставщики, финансы, склад) на ≤560px
превращается в карточку: подпись колонки слева, значение справа, кнопки и
выпадающие списки — на всю ширину.
- На каждый `<td>` добавлен `data-label`;
- CSS-трансформация `display:block` + `td::before { content: attr(data-label) }`.

## v11 — 2026-06-04
**Fix:** контент модалки уезжал за левый край на узких экранах.
- Корень: `input/select/textarea` без `width:100%` + `min-width:0` не сжимались
  в grid/flex и раздували окно шире экрана;
- `.form-group` и поля: `width:100%`, `min-width:0`, `box-sizing:border-box`;
- `.order-item-row > * { min-width:0 }`; `body { overflow-x:hidden }`.
- Замер: было переполнение `modal-body` +109px → стало 0.

## v10 — 2026-06-04
**Мобильная переработка:** компактнее (меньше паддинги/gap → больше влезает без
скролла), отступы у модалки, высота `100dvh` (низ не прячется под адресной
строкой Safari), фикс обрезки таблицы товаров в карточке заказа.

## v9 — 2026-06-03
Модалка на телефоне: отступы по краям + скругление вместо прижатой к краям
(`.modal-overlay padding`, `border-radius`, `padding-bottom` под Safari-бар).

## v8 — 2026-06-03
Крупная кнопка ✕ закрытия модалки (44×44 — нормальный touch-target),
sticky-заголовок, отступы.

## (без версии) — 2026-06-03
**Сквозная синхронизация разделов:** `rerenderActiveSection()` пересчитывает
открытый раздел после любого изменения (платёж, операция, товар, статус) —
метрики, долги и таблицы остаются согласованными.

## Начальная версия — 2026-06-03
Первый деплой на GitHub Pages (`mentori1/crmokna`):
- 7 разделов: Дашборд, Заказы, Доставка, Клиенты, Поставщики, Финансы, Склад;
- Логин-экран для публичной версии (хеш в `AUTH_HASH`, localhost — без логина);
- Демо-данные (обфускация ФИО/телефонов), реальные — в бэкапе;
- Кнопка запуска `Открыть CRM.command` (Python http.server);
- Ключ Google API и реальные данные исключены из репозитория.

## Более ранние вехи (до GitHub, локальная разработка)

- **Синхронизация через Google Sheets API** (`import/sync_sheets.py`) —
  исправлена потеря ~3127 заказов (фильтр по дате вместо номера). Итог:
  **4941 заказ, 2021–2026, выручка ~151 млн ₽, прибыль ~34 млн ₽**.
- **Поле «Размеры»** в позициях заказа — авто-появление для окон/дверей и т.п.
- **Добавление платежей** в карточке заказа (клиент платит частями) +
  кнопки «+ Операция» (Финансы), «+ Товар» / «Приход» (Склад).
- **Раздел «Доставка»** со статусами доставки открытых заказов.
- **Ручной ввод** клиентов/поставщиков/продукции (свободный ввод + автосоздание).
- **Период на дашборде** (30 дней / Квартал / Полгода / Год / Всё время).
- Первичный импорт из CSV → переход на XLSX (реальные даты) → на API.
